# 🧠 MindCare - Sistema de Gestão Psicológica

Sistema completo para gerenciamento de consultórios de psicologia, desenvolvido como projeto acadêmico.

## 📋 Funcionalidades

- ✅ **Login e Autenticação**
- ✅ **Dashboard** com visão geral
- ✅ **Gestão de Pacientes** (CRUD completo)
- ✅ **Agenda de Consultas**
- ✅ **Controle Financeiro**
- ✅ **Relatórios**
- ✅ **Configurações do Sistema**

## 🚀 Como Executar

### Pré-requisitos

- Node.js (versão 14 ou superior)
- MySQL (versão 5.7 ou superior)
- Navegador moderno

1. **Clone ou extraia o projeto**
